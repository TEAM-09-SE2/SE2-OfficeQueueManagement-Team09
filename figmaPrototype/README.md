# Figma Prototype

Questa cartella raccoglie immagini, flussi e riferimenti esportati da Figma per il progetto.

## Cosa mettere qui

- Screenshot delle schermate principali
- Flussi utente (es. prenotazione, check-in, gestione coda)
- Note visive per UI/UX

## Convenzione consigliata per i file

Usa nomi chiari e coerenti, ad esempio:

- `2026-10-07_home.png`
- `2026-10-07_flow-prenotazione.png`
- `2026-10-07_dashboard-admin.png`

## Struttura facoltativa

Se vuoi, puoi organizzare la cartella con sottocartelle:

- `screens/`
- `flows/`
- `notes/`

## Nota

Questa directory e pensata come archivio rapido delle risorse di prototipazione.
